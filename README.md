# Qibla Finder

A standalone Jetpack Compose Android app with:

- Light and dark mode UI.
- Three bottom navigation tabs: Prayer, Qibla, and Chat.
- Auto-location prayer times from Aladhan via Retrofit.
- SharedPreferences prayer cache that is shown first and refreshed at most once per day.
- Accurate Qibla compass wheel for finding the direction of the Kaaba.
- Local safe Islamic chat guardrails for fatwa, abusive, romantic, violent, and unsafe requests.

Open this folder in Android Studio and sync Gradle. The app requests location for prayer and Qibla features.
